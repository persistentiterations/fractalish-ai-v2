# Investor Demo Notes — Fractalish AI v0.1

## One-liner

Fractalish AI is a local-first activation runtime for process-aware AI: it reads form, preserves uncertainty, compares against baselines, and records its reasoning state.

## Demo pitch

Current AI systems answer fluently but often lose process, source, uncertainty, and state. Fractalish AI demonstrates a lightweight runtime where every activation produces traceable perception, reasoning, uncertainty, cost, and continuity records.

The v0.1 demo runs fully offline. No API keys. No cloud dependency.

## What to show

1. `demo_full_runtime.py` — full spine in one command
2. `outputs/demo_full_runtime/session_glyph.json` — carry-forward state
3. `outputs/demo_mcva/mcva_records.json` — ternary morphology gate
4. `outputs/demo_natural_math/natural_math_comparison.json` — memory vs baseline
5. `public/index.html` — field-lab style local report page
