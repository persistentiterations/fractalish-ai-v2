Fractalish AI v0.1

Local-first prototype integrating Natural Math (process), Fractalish / MCVA (morphology), and Cognitive Basin Core (state / guard).

Doctrine

Natural Math generates process. Fractalish reads the shape left by process. Cognitive Basin preserves reasoning state across process.

Three layers

  • Natural Math — bounded local process engine (v3.6 trunk)
  • Fractalish / MCVA — morphology readout: MCVA / HOLD / AMCVA
  • Cognitive Basin Core — PERCEPT → ATAL → RIGOR → CIRCUIT → GUARD → SERA → SessionGlyph

What this is not

  • Not consciousness or sentience
  • Not an agent army or chatbot skin
  • Not proof of intelligence or AGI
  • Not medical, legal, or disaster prediction

HOLD before false closure. Operator sovereignty always. No network required.
