# Cognitive Basin Simulation v1

First visible **moving-basin simulation**. Shows a stateful event flowing through:

```
ReceptorEvent / PERCEPT → ATAL → RIGOR → CIRCUIT → FractalMemoryMap → GUARD → SERA → SessionGlyph
```

## What it is

- Stateful basin simulation with simulated continuity
- FractalMemoryMap as retrieval topology over CIRCUIT
- Eight doctrine scenarios (false closure, contradiction, pressure, similarity, MCVA, Natural Math, recovery)

## What it is not

- Not consciousness, sentience, AGI, or proof of intelligence
- Not a chatbot, agent army, or Field App
- Not medical/legal/financial/disaster prediction
- No cloud, APIs, vector stores, or LLM wrappers

## FractalMemoryMap usage

CIRCUIT records are mirrored into FractalMemoryMap: nodes, contradiction links, recovery routes, analogy links, HOLD/fog regions. `nearest_active_attractors()` uses transparent scoring — not vector search.

## Scenarios

1. Stable Project Continuity  
2. False Closure Attempt  
3. Contradiction Scar  
4. Pressure Is Not Truth  
5. Similarity Is Not Identity  
6. MCVA Cannot Short-Circuit GUARD  
7. Natural Math Process Trace  
8. Recovery After Interruption
